# <img src="public/favicon.svg" width="32" height="32" valign="middle" /> Eating Ball

React + Vite + TypeScript로 만든 간단한 격자 기반 먹이 수집 게임입니다.\
Claude AI와 함께 제작했습니다. [2026-05-12 프로젝트 시작]

## 게임 소개

4×4 격자 위에서 캐릭터를 움직여 먹이를 먹는 게임입니다. 먹이는 0.5초마다 랜덤한 위치에 등장하며, 캐릭터가 먹이 위치로 이동하면 즉시 수집됩니다.

**수동 모드**와 **자동 모드** 두 가지 플레이 방식을 지원합니다.

## 기술 스택

- **React 18** — UI 렌더링 및 상태 관리 (`useReducer`)
- **TypeScript** — 정적 타입 검사
- **Vite 5** — 개발 서버 및 빌드 도구

## 게임 규칙

- 먹이는 설정한 주기마다 빈 칸에 하나씩 생성됩니다 (기본값 0.5초).
- 캐릭터가 먹이가 있는 칸으로 이동하면 먹이를 수집하고 점수가 1 오릅니다.
- 격자 밖으로는 이동할 수 없습니다.
- **점수 초기화** 버튼(모드 전환 버튼 왼쪽)으로 점수를 0으로 리셋할 수 있습니다.

## 먹이 생성 주기 설정

화면 하단의 입력 칸에서 먹이 생성 주기를 초 단위로 직접 입력할 수 있습니다.

- 숫자와 소수점만 입력 가능합니다 (예: `0.3`, `1`, `2.5`).
- 최솟값은 0.1초이며, 유효하지 않은 값 입력 시 0.5초로 동작합니다.
- 값을 변경하면 즉시 적용됩니다.

**생성 중지 / 생성 시작** 버튼으로 먹이 생성을 일시 중단하거나 재개할 수 있습니다.

생성 중지 버튼과 먹이 생성 주기 입력 칸은 격자 오른쪽 사이드 패널에 위치합니다.

## 언어 전환

격자 왼쪽 패널의 셀렉트 박스로 언어를 전환할 수 있습니다. 셀렉트 박스 왼쪽의 언어 라벨을 포함한 모든 UI 텍스트가 즉시 전환됩니다.

지원 언어: 한국어, 영어, 중국어(간체), 일본어

## 조작 모드

화면 하단의 버튼으로 모드를 전환합니다.

### 수동 모드 (기본값)

방향키(↑ ↓ ← →)로 캐릭터를 직접 이동합니다.

### 자동 모드

캐릭터가 가장 가까운 먹이(맨해튼 거리 기준)를 스스로 찾아 이동합니다.

- 0.5초마다 한 칸씩 이동합니다.
- 거리가 같은 먹이가 여러 개이면 먼저 생성된 먹이를 우선 타깃으로 삼습니다.
- 먹이가 없으면 제자리에서 대기합니다.
- 이동 시 CSS transition으로 부드럽게 슬라이드됩니다.

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (포트 3010)
npm run dev
```

브라우저에서 `http://localhost:3010` 으로 접속합니다.

## 빌드

```bash
npm run build
```

빌드 결과물은 `dist/` 폴더에 생성됩니다.

## 경로 별칭

`@` 는 `src/` 디렉토리의 절대 경로 별칭입니다. `vite.config.ts`와 `tsconfig.json`에 설정되어 있습니다.

```ts
import { useGame } from '@/hooks/useGame'
import { GRID_SIZE } from '@/game/constants'
```

## 프로젝트 구조

기능별로 레이어를 분리하여 구성합니다.

```
eatingBall/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── src/
    ├── game/
    │   ├── types.ts       # Pos, State, Action 등 타입 정의
    │   ├── constants.ts   # 격자 크기, 인터벌 등 상수
    │   └── reducer.ts     # 게임 로직 및 상태 reducer
    ├── hooks/
    │   └── useGame.ts     # 키 입력·타이머 effect를 묶은 커스텀 훅
    ├── App.tsx            # 렌더링 전담 컴포넌트
    ├── App.css            # 게임 스타일
    ├── index.css          # 전역 스타일
    ├── main.tsx           # 앱 진입점
    └── vite-env.d.ts
```
